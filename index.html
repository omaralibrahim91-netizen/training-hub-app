Screen

Notifications reach the lock screen when the app is on your Home Screen; the phone asks for permission the first time you switch this on. In a plain browser tab they may not appear — the Ring handoff below stays the bulletproof option.

Ring through the lock screen

A web page cannot alert you once the screen locks. The Clock app can. Build a Shortcut called “Rest Timer” that takes its input in seconds and runs Start Timer, then turn this on — every rest hands its countdown to Clock, which rings even on silent.

GitHub backup

Pushes your data to backups/training-hub-data.json in a private repo — every push becomes a version in the repo's history. Make a fine-grained token (github.com → Settings → Developer settings) scoped to that one repo with Contents: read and write. The token never leaves this device and is stripped from every backup — but it does sit unencrypted in this browser's storage, so use one you can revoke.
